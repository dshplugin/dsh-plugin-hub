DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes updates and installs that could silently keep an older version. Website: <https://dsh-plugin.org>

## What's fixed

- **Updating an npm plugin now actually upgrades it.** The installer used to pass only the package name. When the profile already held an exact version, pnpm treated the bare name as satisfied, printed `Already up to date`, and the update changed nothing. Installs and updates now ask for the latest release explicitly (`<package>@latest`).
- Hub self-updates still pin the version offered by the version endpoint, and Git targets and global installs are passed through unchanged.

Note: because the latest release is now requested explicitly, a package whose newest version is less than 24 hours old is refused by pnpm's supply-chain hold instead of silently falling back to an older version, and the error states when it can be retried.

If you are stuck on an older version, update from a terminal:

```bash
dsh plugin --profile <your-profile> add dsh-plugin@2.2.4
```

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
