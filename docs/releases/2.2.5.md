DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release stops the update badge from appearing before the supply-chain check has finished. Website: <https://dsh-plugin.org>

## What's fixed

- **The update badge no longer flashes.** It was lit as soon as the installed version was behind, then withdrawn a moment later once the npm release check came back — the newest release was still inside pnpm's 24.5-hour supply-chain hold. The badge now waits for that check, so what you see is what you can install. Reported in #505.
- **A held update is explained instead of silently dropped.** When the newest release is still inside the hold, the card, the installed list and the detail dialog say when it can be installed (for example "Update available after 23:44") instead of falling back to "installed".

If you are stuck on an older version, update from a terminal:

```bash
dsh plugin --profile <your-profile> add dsh-plugin@2.2.5
```

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
