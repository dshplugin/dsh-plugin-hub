DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes runtime-path detection on Android, so installing and updating plugins through the Hub works again. Website: <https://dsh-plugin.org>

## What's fixed

- **Every plugin install or update failed on Android.** The installer re-launched the DSH CLI through the wrong executable, so the command died with `error: expected absolute path: "--expose-internals"` before the package manager ever ran — any plugin, not just one. It now resolves the real runtime entry point and the install proceeds normally.
- **Host restart was broken by the same cause.** The restart helper now uses the same runtime resolution.

## Note for Android users

Builds released before this version cannot update themselves in-app (self-update goes through the same path), so install this one manually once — reinstall or side-load 2.2.6. In-app updates work normally afterwards.

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
