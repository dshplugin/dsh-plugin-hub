DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release tightens failure attribution and fixes an edge case that could corrupt the profile config. Website: <https://dsh-plugin.org>

## What's fixed

- **A corrupted profile YAML config is now recognized.** When pnpm hits a duplicate key while reading `pnpm-workspace.yaml` or `pnpm-lock.yaml` inside the profile, the dialog shows how to fix it (remove the duplicated key; if unsure, delete `pnpm-lock.yaml` and reinstall) instead of calling it plugin distribution incomplete. No issue link is offered: every plugin fails that way in that profile, so it is not about the plugin you were installing (#562).
- **The installer no longer writes a second `allowBuilds` key.** When the existing setting used an inline value, or was a bare header at the end of the file, the installer appended another block - leaving the file with two `allowBuilds` keys, after which pnpm aborts with `duplicated mapping key` and nothing can be installed into that profile. Any existing form is now normalized into a single block, keeping the entries that were already there.

If you are stuck on an older version, update from a terminal:

```bash
dsh plugin --profile <your-profile> add dsh-plugin@2.2.7
```

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
