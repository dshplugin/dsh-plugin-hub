DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release reworks the information hierarchy of the marketplace and installed lists, so long repository names no longer hide the version and update state, and author and popularity details are visible at a glance. Website: <https://dsh-plugin.org>

## What changed

- **Marketplace cards use separate rows.** Name, version and update state stay on the first line, while the category and verified badges move to their own row; long repository names truncate instead of pushing the title out of view.
- **Marketplace cards show the author.** The author handle (@name) appears ahead of the category and verified badges.
- **Plugin names and repository names are links.** Clicking either one opens the matching plugin page on the website, while clicking elsewhere in a row still opens the local dialog.
- **The installed list matches the new layout.** Name and version share one line, Star / Fork counts sit in the top-right corner, and the source tag (Plugin Hub / Manual install) moves to the second line.
- **Installed-row actions form their own row.** Reveal in Finder, Install details, Update and Uninstall are right-aligned together; Reveal in Finder stays borderless until hovered so the low-frequency action does not compete for attention.
- **The installed list gains an Install details button.** It opens the same local install dialog as clicking the row body, without having to know the row is clickable.
- **Badges and buttons share one size scale.** Small badges and row actions no longer render at visibly different sizes.

## Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
