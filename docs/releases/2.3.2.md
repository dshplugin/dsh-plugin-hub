DSH Plugin Hub is the community plugin marketplace plugin for DeepSeek Harness — https://dsh-plugin.org

This release fixes plugin installs being silently downgraded by pnpm's release-age gate.

### What's fixed

- **No more silent downgrades on install.** Installing from the marketplace now pins the highest stable version already past the 24-hour release-age gate, instead of landing on a much older release with missing features (thanks @liaoguogang-hub for the detailed reproduction — #586).
- **Commands match what actually runs.** The install confirmation dialog and the copyable install command now include the exact version being installed, so a hand-copied command behaves like the one-click install.
- **Actionable error when the registry lags.** If the registry in use has not synced that version yet, the message now suggests retrying later, switching to the official npm registry, or installing the previous available version.
- **Version resolution follows the registry that installs.** The gate lookup uses the same registry as the actual install (the configured mirror or the local npm config), so the pinned version always exists where it is downloaded from.
- **"Follow us" dialog** now points to the website and to opening an Issue on GitHub.

### Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
