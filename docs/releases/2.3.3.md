DSH Plugin Hub is the community plugin marketplace plugin for DeepSeek Harness — https://dsh-plugin.org

This release fixes a false failure when uninstalling a plugin that is already gone.

### What's fixed

- **Uninstalling an already-removed plugin no longer fails.** When pnpm answers "no such dependency found", the hub now treats it as uninstalled: the installed list refreshes, the result is recorded as success, and no failure dialog or issue prompt appears.
- **Uninstall failures are labelled correctly.** Notifications and the auto-filed issue title now say "uninstall failed" instead of "install failed".
- **Stale installed lists self-heal.** If the list and the local dependencies briefly disagree — for example, uninstall clicked twice before the list refreshed — the hub now recovers instead of reporting an error.

### Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
