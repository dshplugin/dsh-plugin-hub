DSH Plugin Hub is the community plugin marketplace plugin for DeepSeek Harness — https://dsh-plugin.org

This release fixes catalog links for plugins whose repository names contain uppercase letters.

### What's fixed

- **Catalog links no longer land on a 404.** The hub built the website URL from the repository name as written, but the site only publishes lowercase owner/slug paths. Links for mixed-case repositories — `HuaGuoXingKong/dsh-prompt-rewriter`, for example — now point at the lowercase URL, so "View details" in the installed list and the Catalog link in failure reports open the plugin page instead of a 404.
- **Plugin submissions now collect what the scanner needs.** The submission form requires one of the existing 11 categories and confirms the `dsh-plugin` topic plus a matching `repository` field, so a submission can no longer be silently undiscoverable.

### Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
