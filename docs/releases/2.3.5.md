DSH Plugin Hub is the community plugin marketplace plugin for DeepSeek Harness — https://dsh-plugin.org

This release fixes the marketplace failing to load on machines whose curl was built without zlib.

### What's fixed

- **The marketplace loads again when the local curl cannot compress.** Some Windows curl builds ship without zlib and reject `--compressed` before any request is sent, which left the catalog endpoint returning 502 and the marketplace stuck on "plugin data failed to load". The hub now detects that unsupported option and retries once with a plain request, so the catalog downloads normally.
- **Older curl builds no longer hide the real error.** When a fallback flag such as `--http1.1` is also unsupported, the first genuine failure is kept instead of being replaced by an unrelated option error, so the details shown in failure reports stay accurate.

### Install

dsh plugin --profile web add dsh-plugin

dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
