DSH Plugin Hub is the community plugin marketplace plugin for DeepSeek Harness — https://dsh-plugin.org

This release makes a silent installation failure diagnosable, instead of reporting a bare "install failed".

### What's changed

- **A failure that prints nothing now carries the facts needed to investigate.** When the installer exits with only its wrapper line (`Command failed with exit code 1: pnpm add …`), the hub records the exact command and working directory that ran, the profile location, and the npm registry it talked to.
- **Failure reports name the npm registry in use.** The environment section of a prefilled issue now shows the registry the install actually used — a configured mirror, the local npm configuration, or the public default — so mirror and connectivity problems are visible instead of guessed. Private registry addresses are reduced to their host, so credentials never reach a public issue.
- **The environment snapshot copied from Settings includes the same registry line.**

### Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
