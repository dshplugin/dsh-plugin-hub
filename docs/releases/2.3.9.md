DSH Plugin Hub is the community plugin marketplace plugin for DeepSeek Harness — https://dsh-plugin.org

This release repairs a poisoned `allowBuilds` entry that made every install into a profile fail, and stops the hub from creating one.

### What's changed

- **An unparsable `allowBuilds` entry no longer breaks every install.** pnpm validates each `allowBuilds` rule as `package@exact-version` before resolving anything; a rule such as `dsh-purge@https://…` or `pkg@file:…` makes it abort with `ERR_PNPM_INVALID_VERSION_UNION`, so no plugin can be installed into that profile. The hub now rewrites such keys to the bare package name before installing, which unblocks the profile.
- **The hub no longer writes URL or path specs into `allowBuilds`.** Keys harvested from pnpm output are normalized first: only `package@semver` is kept verbatim, everything else falls back to the bare package name.
- **That failure is attributed to the profile, not to the plugin or the hub.** It is classified as a local profile state and shows the fix (edit `pnpm-workspace.yaml`, keep `package: true`), instead of asking for an issue against the plugin being installed.

### Install

```bash
dsh plugin --profile web add dsh-plugin
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
