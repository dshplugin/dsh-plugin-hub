**v1.0.0 — First Official Release**

After sustained refinement and architectural evolution across the 0.1.x series, DSH-Plugin Hub today ships version 1.0.0. This release marks the marketplace's journey from preview to maturity — a complete engineering rebuild that redefines how plugins are managed from within the application.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**Highlights**

- **One-click install / update / uninstall** — fully visual flows with live progress and the freedom to cancel at any time; changes take effect immediately, no host restart required
- **Notification center** — task progress, pending restarts, and operation history in one place; failed tasks can be reported to GitHub Issues with a single click
- **Bilingual interface** — follows your system language automatically, with a one-click manual switch
- **A rich, human-curated catalog** — 4,261 community plugins indexed, 2,487 human-verified; browse by category, full-text search, multi-dimensional sorting, and installed-status filtering
- **Live data sync** — data is sourced from dsh-plugin.org and refreshed daily
- **Lightweight & private** — browser-only injection, no host service dependency, no telemetry, no data collection

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add github:dshplugin/dsh-plugin-hub
```
