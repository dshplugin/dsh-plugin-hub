**v1.1.0 — A stronger install pipeline for the community marketplace**

DSH-Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release sharpens the install experience across every channel — raising the success rate for community plugins, keeping install state accurate, and making failures easy to diagnose. A meaningful step toward a mature marketplace.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**Highlights**

- **Multi-channel installs** — The hub automatically picks the best channel for each plugin: the npm registry when a package is available, with a seamless fallback to GitHub source installs — both distribution styles fully supported
- **Automatic npm discovery** — Point at a GitHub repository and the hub recognizes its matching npm package and installs it directly, no manual package hunting
- **Diagnosable failures** — When an install fails, every channel and command attempted is collected and can be filed to the plugin author in one click, helping issues get resolved faster with the community
- **Instant install status** — Fixed cases where a successful install still appeared as "not installed"; the list now reflects the true state right away
- **More robust local services** — Hardened the development and restart flows so interrupted syncs can no longer leave the service unable to boot

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add github:dshplugin/dsh-plugin-hub
```
