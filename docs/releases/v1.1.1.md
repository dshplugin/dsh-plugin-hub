**v1.1.1 — A refined install, uninstall, and update experience**

DSH-Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release completes the install journey — more forgiving one-click installs, cleaner uninstalls, and updates within reach — so the marketplace feels dependable from the first click to every day after. The catalog now indexes 4,603 community plugins, of which 4,300 have been hand-verified, refreshed daily at dsh-plugin.org.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**Highlights**

- **More forgiving one-click installs** — Plugins that may need command-line help can still be attempted with a single click; if the attempt fails, the exact command is surfaced for you to run
- **Cleaner uninstalls** — Removing a plugin that carries a UI now asks for a restart, so its sidebar panel disappears immediately instead of lingering on screen
- **Restart reminders that stay** — Choose "Later" and the reminder remains in the notification center until the restart truly happens
- **Updates at your fingertips** — A built-in update check brings the latest hub to you, no need to keep track of releases
- **An "About Us" panel** — A closer look at the marketplace and how to reach the community behind it
- **A purer catalog** — The marketplace no longer lists itself, keeping the catalog focused on community plugins

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add github:dshplugin/dsh-plugin-hub
```
