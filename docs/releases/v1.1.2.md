**v1.1.2 — Reliable GitHub installs for every environment**

DSH-Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release removes a source of instability in one-click installs: plugins installed directly from GitHub now use an explicit HTTPS source, so installation no longer depends on environment-specific SSH configuration. The catalog now indexes 4,805 community plugins, of which 4,401 have been hand-verified, refreshed daily at dsh-plugin.org.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**Highlights**

- **Reliable installs from GitHub** — Plugins installed directly from GitHub now use an explicit HTTPS source, so public repositories install without any SSH keys or environment-specific configuration. Thanks to @GanyuanRan for the report and contribution.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
