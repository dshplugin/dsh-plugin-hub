**v1.2.1 — More Reliable Update Checks**

DSH-Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release makes update checks more dependable: version and "About us" information are now published as static data from the dedicated plugin data center, so every installed client receives fresh release notes promptly and consistently. The catalog now indexes 4,805 community plugins, of which 4,401 have been hand-verified, refreshed daily at dsh-plugin.org.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**Highlights**

- **More reliable update checks** — Version and "About us" content are now delivered as static data from the dedicated plugin data center, so release notes reach every installed client promptly and consistently, with no stale or missing updates.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
