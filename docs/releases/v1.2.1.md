**v1.2.1 — More Reliable Update Checks**

DSH-Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release requires an update on every installed machine: version and "About us" information now come from a new data endpoint, so machines running earlier versions will no longer receive update notifications. The catalog now indexes 4,805 community plugins, of which 4,401 have been hand-verified, refreshed daily at dsh-plugin.org.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**Highlights**

- **Required update for all installations** — Every installed machine must update to v1.2.1. Version and "About us" content are now delivered from a new data endpoint; machines on earlier versions will no longer receive release notifications. Update now to keep your hub up to date.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
