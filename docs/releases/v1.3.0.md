**v1.3.0 — Clearer Installs, Timelier Updates**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release sharpens custom installs with full command support and built-in help, while making update notifications smarter and more immediate.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Clearer custom installs** — NPM packages, GitHub sources and DSH commands now work as three independent channels, each with a "Help" modal listing every supported command form; the NPM channel accepts full native commands, including global installs
- **Smarter update reminders** — Opening the hub checks for new versions automatically; you can dismiss a release in the notification center with one click, and it won't remind you again until the next release
- **Release notes delivered instantly** — Clicking the version number fetches the latest announcement immediately, free of caching delays
- **A calmer dark mode** — Colored action buttons converge to neutral gray, while destructive actions like uninstall keep their red warning
- **Consistent update badges** — The "Update available" badge in Installed view now matches the marketplace's amber style
- **Faster hub startup** — Catalog data is cached locally for instant opening and refreshed hourly

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
