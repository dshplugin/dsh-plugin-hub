**v1.3.1 — Precise Feedback, Self-Aware Installs**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release refines custom installs and issue reporting for a smoother, more reliable experience.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Install the hub from the command window** — Custom commands can now target the hub itself, reinstalling or updating it without being blocked as already installed
- **Issue reports land on the right repository** — The one-click feedback button resolves a plugin's real GitHub repository automatically; when the source cannot be identified, the button is hidden instead of opening a wrong address
- **The hub stays out of its own installed list** — After installing or updating itself, the hub no longer appears among installed plugins, keeping the list clean

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
