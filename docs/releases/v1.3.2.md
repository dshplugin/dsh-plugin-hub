**v1.3.2 — Updates That Really Update**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release makes updates trustworthy — a successful update now always brings the new version with it.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Updates truly take effect** — When updating an installed plugin, the reinstall now explicitly targets the latest release, so the new version always lands; previously the update could be treated as "already up to date" and silently leave the old version in place

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
