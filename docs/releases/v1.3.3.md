**v1.3.3 — Polish for interactions and stability**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release sharpens the confirmation experience and hardens the interface: every destructive action now asks before it acts, and two occasional UI issues are gone.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Confirmations that match the action** — Install, uninstall, clearing records, ignoring an update and resetting settings each open a dedicated confirmation dialog with an icon that mirrors what is about to happen, so nothing risky happens by accident
- **Protected restarts** — Every "Restart Now" entry now asks for confirmation first, preventing an accidental restart from interrupting an install that is still in progress
- **The market no longer freezes** — If loading the plugin list stalls, the page now auto-refreshes once the request times out instead of staying stuck
- **Styles always come back** — After a host restart, buttons and lists occasionally appeared without styling; they now restore themselves automatically on load

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
