**v1.3.4 — Windows compatibility fixes**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes two issues that specifically affected Windows users: restarting the host after a plugin change, and the npm environment check.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's Fixed**

- **Host restart now works on Windows** — "Restart Now" previously relied on `/bin/sh` plus `lsof`/`nohup`, which do not exist on Windows, so the restart silently failed (GitHub issue #7). The restart now spawns a cross-platform script: it finds whatever process is listening on the port (`netstat` on Windows, `lsof` on macOS/Linux), stops it, and launches `dsh web` again.
- **npm version check now works on Windows** — When an install fails because the local npm is too old, the plugin now detects and reports the accurate reason on Windows as well. npm is a `.cmd` shim there, so it must be invoked through the shell.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
