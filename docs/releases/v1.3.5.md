**v1.3.5 — Custom install commands now support updates**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release lets the custom install panel accept the official `dsh plugin update` command, and adds a one-click shortcut to update DSH Plugin Hub itself.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Update from the custom install panel** — paste the official `dsh plugin --profile <name> update <plugin>` command to bring any installed plugin up to its latest version. Previously only `add` was accepted and `update` was rejected as invalid input.
- **One-click update for DSH Plugin Hub** — a new button in the command card inserts the update command for DSH Plugin Hub itself, pre-filled with your current profile.
- **About dialog polish** — the user-group QR code is now rendered at a fixed size and no longer overflows the dialog.
- **User group QR code on the README** — scan it on the project homepage to join the feedback group.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
