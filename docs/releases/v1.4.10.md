**v1.4.10 — plugins can be installed again from the desktop (Electron) host**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes the desktop (Electron) host, where no plugin could be installed at all.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Plugins can be installed again from the desktop (Electron) host** — Install requests coming from the desktop host were rejected by the local service as an untrusted origin, and the failure was wrongly shown as a pnpm supply-chain policy block with advice that could not help. The desktop host origin is now accepted, so installs work normally; when a request really does come from an untrusted origin, the notification shows the real reason instead. Thanks to @yuhang0521 ([#70](https://github.com/dshplugin/dsh-plugin-hub/issues/70)).

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
