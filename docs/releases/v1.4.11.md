**v1.4.11 — installs work in the packaged desktop app, and a firewall no longer blocks Git installs**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes the two remaining failure modes reported against the packaged desktop app and locked-down networks.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Plugins can be installed from the packaged desktop app** — In a packaged build the app's CLI entry lives inside `app.asar`, and no `dsh` executable exists on the machine (the Windows `dsh.cmd` shim only exists on the host process's own PATH). The installer fell back to a `dsh` lookup on the PATH, which always failed with `[dsh-missing]`. It now launches the same bundled CLI the app itself uses — the Electron binary running `app.asar/lib/desktop-cli.js` — so installs go through the exact path the built-in terminal uses, including the app-managed desktop profile access ([#71](https://github.com/dshplugin/dsh-plugin-hub/issues/71)).

- **Git installs no longer fail on networks that block the GitHub website** — The pre-install connectivity check probed `https://github.com/` with curl. Firewalls that allow `git clone` but block ordinary HTTPS browsing (or do TLS re-inspection on the web origin) made a perfectly installable repository look unreachable, and the install was aborted as `[network]`. The Git channel is now probed with the same `git ls-remote` handshake pnpm uses to clone; a plain web probe is only used as a second opinion, and the install is aborted as a network problem only when both fail ([#71](https://github.com/dshplugin/dsh-plugin-hub/issues/71)).

- **Windows certificate-revocation checks no longer break every channel** — On Windows machines that cannot reach a certificate revocation list, curl failed with `CRYPT_E_NO_REVOCATION_CHECK` and every channel was reported as unreachable. Probing now retries with `--ssl-no-revoke`, which covers curl releases older than the previous fallback flag. This only relaxes the check for the probe's own request and does not change any system TLS configuration ([#71](https://github.com/dshplugin/dsh-plugin-hub/issues/71)).

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
