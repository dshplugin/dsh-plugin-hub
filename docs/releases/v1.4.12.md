**v1.4.12 — installs from the desktop app no longer fail with `untrusted origin`**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes the request guard that was refusing every install and uninstall sent from the desktop app, and a second case that rejected writes whenever the market page was opened on a different loopback address than the one the app was serving on.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Installing and uninstalling work again in the desktop app** — The guard treated a request that carries no `Origin` header as an untrusted origin, which is exactly what the desktop host sends when it forwards the market's writes to the app's own local server. As a result every install and uninstall started from the app was refused with an `untrusted origin` error, no matter which plugin was chosen ([#72](https://github.com/dshplugin/dsh-plugin-hub/issues/72)).

- **`localhost`, `127.0.0.1` and `[::1]` are now recognised as one and the same address** — The guard compared the page's origin with the server's host as raw text, so a market opened at `localhost:PORT` whose writes went to `127.0.0.1:PORT` (or the reverse) looked like a foreign site and was rejected, even though both name the same machine on the same port. The comparison now goes by loopback address and port, with the port still required to match ([#72](https://github.com/dshplugin/dsh-plugin-hub/issues/72)).

Thanks to [@StoneSho](https://github.com/StoneSho) for the detailed report and environment notes.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
