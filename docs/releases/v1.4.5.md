**v1.4.5 — A local write-permission problem is explained, not blamed on plugins**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release keeps one more local environment failure away from the plugin's name, and the dialog now tells you what actually happened on your machine.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **A write access denial inside the profile is no longer reported as a plugin failure** — On Windows, when the system denies pnpm access to a file inside the profile (os error 5, "Access is denied"; the equivalent Node codes are EPERM / EACCES), the dialog now explains that this is a local file or permission problem, and what to try before retrying.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
