**v1.4.6 — A local storage problem is explained, not blamed on plugins**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release completes the local file-system family: when the disk itself cannot accept the write, the dialog now says so instead of pointing at the plugin.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **A disk that cannot accept writes is no longer reported as a plugin failure** — When the plugin directory runs out of space (ENOSPC, "no space left on device", os error 112 on Windows), sits on a read-only or write-protected volume (EROFS, "read-only file system", os error 19 on Windows), or the process runs out of file handles (EMFILE / ENFILE), the dialog now names the real cause and gives the matching way out — free up space, move the plugin directory to a writable drive, or restart DeepSeek Harness.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
