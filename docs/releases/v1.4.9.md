**v1.4.9 — the desktop host and Windows proxies stop blocking the marketplace**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes the two environments where the marketplace could not be used at all: the Electron desktop host, and Windows with a system proxy enabled.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **The marketplace now loads in the Electron desktop host** — The desktop host does not pass `--profile`; it passes the profile directory as a positional argument. Only the `--profile` form was understood, so the active profile always fell back to `web`: the marketplace could never load its plugin data, and logs and installs were written to the wrong profile. Both host shapes are now recognized, including the `--profile=<name>` form. Thanks to @kinght1510 ([#65](https://github.com/dshplugin/dsh-plugin-hub/issues/65)).
- **Windows system proxies are read correctly** — For a proxy stored as `http://127.0.0.1:10793`, the parser let the host name swallow the `//` and produced `http:////127.0.0.1:10793`, an invalid address. Network diagnostics, catalog fetches and install preflight all reported the network as unreachable even though the proxy itself was working. Values that carry the `http://` scheme are now parsed correctly. Thanks to @kinght1510 ([#66](https://github.com/dshplugin/dsh-plugin-hub/issues/66)).

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
