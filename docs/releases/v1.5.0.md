**v1.5.0 — release installs keep their catalog identity in the installed view**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes how the installed view recognises plugins added from a GitHub release direct link (a prebuilt `.tgz`): they previously lost their owner/repo identity, which broke readback, update detection, and uninstall for those plugins.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Release installs now keep their catalog identity** — Plugins installed via a GitHub release direct link (prebuilt `.tgz`) are now matched back to their directory entry by repository, so the installed view shows the correct owner/repo, detects available updates, and uninstalls cleanly instead of treating them as a custom install ([#98](https://github.com/dshplugin/dsh-plugin-hub/pull/98)).

Thanks to [@loopx-agent](https://github.com/loopx-agent) for the fix.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
