**v1.5.1 — a stale npm target no longer installs a broken plugin**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes installs that failed because the catalog recorded an outdated npm package name.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Plugins whose catalog npm target is outdated now install correctly** — When a listing points at a package that is no longer the repository's DSH plugin, the marketplace now resolves the repository's actual DSH plugin package and installs it, instead of failing after install with a missing entry file ([#111](https://github.com/dshplugin/dsh-plugin-hub/pull/111)).

- **The pre-install check now works for GitHub source packages** — Plugins whose distributed source is missing the declared entry file are caught before installation with a clear message, instead of being installed and crashing the host while it loads the plugin tree ([#111](https://github.com/dshplugin/dsh-plugin-hub/pull/111)).

Thanks to [@fwerkor](https://github.com/fwerkor) for the fix.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
