**v1.5.2 — installing plugins works again in the desktop app**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes installs failing immediately in the DeepSeek Harness desktop app.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Installs no longer fail on the desktop profile** — In the DeepSeek Harness desktop app, every install used to fail right away with `profile "desktop" is managed exclusively by the Electron application`, so no third-party plugin could be added. The marketplace now runs installs through the app's own launcher, and installing, updating and uninstalling plugins work again.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
