**v1.6.0 — install guidance that matches your profile, and clearer pnpm policy messages**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release makes the in-app install guidance accurate on every profile, and gives the supply-chain policy rejections a message you can act on.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **The custom-install help shows your actual profile** — The example, the validation message and the help card hardcoded `--profile web`, so desktop users were told to copy a command that installs into a profile the host never loads. They now render the profile the marketplace itself installs into, so what you copy is what runs.
- **Origin-rejected failures point at the step that works** — When the host rejects a request, the hint only said to restart the host, which cannot help if the installed marketplace is older than the host. It now ends with the upgrade command to run before restarting once.
- **Freshly published packages report when you can retry** — A package less than 24 hours old is rejected by pnpm's minimum-release-age policy, which blocked every install and removal in that profile afterwards. This is now reported separately from the untrusted-origin case, with the exact retry time parsed straight out of the error, instead of the generic "wait 24 hours".

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app. Restart the host once after upgrading.
