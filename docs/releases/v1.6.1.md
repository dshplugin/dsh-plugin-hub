**v1.6.1 — a pinned plugin revision installs as pinned**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes installing a specific version: when you pin a tag or commit on a GitHub target, that exact revision is what gets installed.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **A pinned revision is installed as pinned** — Pinning a tag or commit on a GitHub install target was ignored while the target was resolved, so a different revision could end up installed. The pin is now preserved, and the requested revision is the one that installs. Thanks to @GanyuanRan ([#130](https://github.com/dshplugin/dsh-plugin-hub/issues/130)).

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app. Restart the host once after upgrading.
