**v1.6.2 — the desktop app keeps control of its own restarts**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes "Restart now" in the desktop app: the button no longer shuts the host down, and no longer leaves the app reporting that it stopped unexpectedly.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **"Restart now" no longer closes the desktop app** — On the Windows desktop app, tapping "Restart now" after an install could terminate the host instead of restarting it, and the app then reported that it had stopped unexpectedly. The desktop app owns its host, so the button now asks you to quit and reopen the app for the change to take effect. Thanks to @VK365 ([#139](https://github.com/dshplugin/dsh-plugin-hub/issues/139)).
- **A restart that cannot happen no longer reports success** — If the running host could not be located, the button still reported a restart that never took place; it now says so instead of claiming success.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app. Restart the host once after upgrading.
