**v1.6.3 — plugin changes now apply without a restart**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release reworks how installs and removals are applied: instead of asking you to restart the host, the hub applies the change to the running host and refreshes the page for you.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **"Restart now" is gone from the normal flow** — Installing or removing a plugin used to end with a "Restart now / Later" choice. The hub now applies the change to the running host, and the result dialog just has a single "Done": closing it refreshes the page, so the new plugin (or the removal) shows up right away.
- **The desktop app refreshes the same way** — The desktop app picks up the change on a page refresh just like the web host, so there is no need to quit and reopen the app.
- **A restart is only offered when it is genuinely required** — In the rare cases a page refresh cannot help, the hub still says so and offers a single "Restart now" instead of claiming success.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app. Restart the host once after upgrading the hub itself.
