**v1.6.4 — accurate install guidance for incomplete git distributions**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes the guidance shown when a plugin's git repository does not ship its build output: the old wording recommended a `prepare` script, which modern pnpm versions no longer run.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Install guidance now points at channels that actually work** — When a plugin's git distribution is incomplete, the hub now suggests a complete npm package, committed build output, or a prebuilt release `.tgz` (`releases/download/<tag>/<asset>.tgz`) instead of a `prepare` script. Thanks to @AllureCurtain ([#142](https://github.com/dshplugin/dsh-plugin-hub/issues/142)).
- **The in-app hint and the auto-filed issue now agree** — The install-failure hint and the issue body the hub generates from it describe the same official channels, so reporting a packaging problem asks the author for the fix that will actually resolve it.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app.
