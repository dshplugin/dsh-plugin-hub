**v1.6.5 — accurate version info, reliable install channel after a rename**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes two user-visible problems: the version dialog could report "up to date" while your install was behind (and show the remote version as if it were yours), and a renamed plugin repository could silently fall back to a git install.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **The version dialog no longer claims you are up to date when you are not** — When a newer release exists but is still inside pnpm's 24-hour supply-chain window (where an update is silently rolled back), the dialog used to treat it as "no update" and presented the remote version as your local one. It now shows the version you are actually running and explains why the newer release is being held back; the update entry appears on its own shortly after. Thanks to @kinght1510 ([#145](https://github.com/dshplugin/dsh-plugin-hub/issues/145)).
- **A renamed repository still installs through the right channel** — After a plugin repository is renamed, the hub could no longer match it to its npm package and the install quietly degraded to a git install. It now resolves the package correctly, so a rename no longer changes how the plugin is installed.
- **Docs brought in line with the code** — The architecture, development and reference documents now match the current implementation.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```

Replace `web` with your own profile — it is `desktop` in the DeepSeek Harness desktop app.
