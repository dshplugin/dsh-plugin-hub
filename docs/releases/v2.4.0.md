**v2.4.0 — A broken local pnpm is now named as such**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release improves how install failures are diagnosed: problems with the local environment are no longer mistaken for a plugin's own install failure.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **A broken local pnpm is reported as an environment problem** — When the pnpm entry module is missing on the machine (a wiped global store link, or a bundled runtime that was never shipped), the hub now says so and points to reinstalling pnpm or using the in-app installer, instead of offering to file an issue here.
- **No more "plugin-side install failure" for this case** — The failure no longer falls through to the unclassified path, so the report no longer misattributes it to the plugin.
- **Environment and distribution problems are separated** — The failure dialog and the notifications panel now give different guidance for problems on your machine and problems in a plugin's distribution.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
