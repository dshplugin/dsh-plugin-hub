**v2.4.1 — The language toggle keeps to the two languages the host ships**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes the settings header language switch, which could land on a language the host does not support.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **The language toggle cycles between Chinese and English only** — The header button no longer rotates through Portuguese, which the host does not ship, so a click always leads to a fully translated interface.
- **Unsupported languages fall back to English** — Any locale without a bundled dictionary now resolves to English instead of Chinese.
- **Smaller bundled client** — The unused Portuguese interface strings were removed.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
