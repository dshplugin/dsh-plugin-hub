**v2.4.3 — Installs no longer trip over a UTF-8 BOM**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This patch fixes install failures caused by a byte-order mark in the profile manifest.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **BOM in the profile manifest no longer aborts installs** — Windows editors add a UTF-8 BOM by default, and the JSON parser rejects it with `SyntaxError: Unexpected token '\uFEFF'` before the install even starts. The BOM is now stripped from the profile's `package.json` ahead of the run, and a `[bom-stripped]` line is written to the log.
- **Version verification tolerates a BOM** — Reading the installed package manifest no longer fails silently on profiles saved with a BOM.

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
