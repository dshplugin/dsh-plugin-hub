**v2.4.4 — Steadier installs: no more mojibake in Chinese logs, clearer registry errors**

DSH Plugin Hub is the community plugin marketplace for DeepSeek Harness. This release fixes two installation problems and turns a misconfigured npm registry into a readable message instead of a low-level error.

**Website**: [dsh-plugin.org](https://dsh-plugin.org)

**What's New**

- **Install logs on Chinese Windows are readable again** — GBK multibyte characters split across output chunks now decode correctly, so progress and error lines no longer turn into garbled text (thanks @simpleqt, #882).
- **npm registries over http:// are supported** — Self-hosted and internal mirrors configured as `http://…` no longer abort the install with `Protocol "http:" not supported`.
- **Invalid registry URLs fail fast with a clear message** — If the npm registry is missing a scheme or uses an unsupported one, the install stops before starting and points at Settings → npm registry.
- **README refreshed** — Screenshots now match 2.4.x, and the catalog counts are updated (27,000+ plugins, 7,000+ installable from npm in one click).

**Installation**

Option 1 · via npm (recommended):

```bash
dsh plugin --profile web add dsh-plugin
```

Option 2 · via the official GitHub repository:

```bash
dsh plugin --profile web add git+https://github.com/dshplugin/dsh-plugin-hub.git
```
